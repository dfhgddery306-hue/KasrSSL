# EDITOR TRUE – SKY BLUE (Android starter project)

واجهة عربية داكنة بلمسات أزرق سماوي، مع اختيار ملف APK/ZIP وقائمة خيارات أولية.

## رفع المشروع إلى GitHub من الهاتف
1. نزّل ملف `APKPatcher-Mobile-source.zip` وفك ضغطه على الهاتف إن أمكن.
2. أنشئ مستودعاً جديداً على GitHub باسم `APKPatcher-Mobile`، واختر Private أو Public.
3. من صفحة المستودع اختر **Add file → Upload files**.
4. ارفع محتويات مجلد `APKPatcher-Mobile` (بما فيها مجلد `.github`؛ قد تحتاج إظهار الملفات المخفية) ثم اضغط **Commit changes**.
5. افتح تبويب **Actions** وانتظر سير العمل `Build Android APK`.
6. عند نجاح البناء، افتح التشغيل الأخير ونزّل Artifact باسم `EDITOR-TRUE-debug-apk`.

## ما الذي يتضمنه هذا المشروع؟
- تطبيق Android أصلي بسيط يحتوي WebView لعرض واجهة EDITOR TRUE باللون الأزرق السماوي.
- اختيار ملف من الهاتف عبر منتقي ملفات Android.
- سير عمل GitHub Actions لبناء APK تجريبي ورفع الناتج كـ Artifact.

## حدود النسخة الحالية
هذه نسخة أولية للواجهة فقط. لم يتم دمج محرك تعديل APK الموجود في `APKPatcher.jar`، ولم تُنفذ عمليات الباتش فعلياً. زر بدء المعالجة يعرض تنبيهاً واضحاً ولا يغيّر الملف. يلزم فحص مصدر المحرك واعتمادياته وتكييفه لأندرويد قبل توفير وظائف تعديل حقيقية.

## المتطلبات
- Android SDK 35 للبناء، Java 17، Gradle 8.9.
- التطبيق مناسب للتجربة على Android 14 وما بعده.
