# كسر SSL — مشروع Android أولي
- تطبيق Android مستقل، لا يحتاج إلى VPS أو Telegram.
- اختيار APK من الهاتف.
- قراءة اسم التطبيق والحزمة والإصدار والحجم والصلاحيات.
- واجهة عربية داكنة مستوحاة من التصميم.
- لا يتجاوز SSL Pinning ولا يعطل التحقق من الشهادات ولا يعدل حماية تطبيقات الغير.

## البناء
افتح المجلد في Android Studio، ثم انتظر Gradle Sync، وبعدها Build > Build APK(s).
يتطلب Android SDK 35 وJDK 17.
